# 文献卡（lit_card）模板

> 每篇一张，5 行填满。第三人称写，方便直接引用进 Gap 定位图。

```yaml
标题: 
作者/年份: 
来源: 期刊/NBER WP/arXiv/工作论文

问题: 这篇在回答什么问题？
方法: 识别策略 + 估计量（DiD/IV/RDD/结构断点/ML/…）
数据: 数据源 + 口径 + 样本量（与自己的可得性对照）
结论: 核心系数方向与量级 + 边际贡献声明
缝: 它没回答什么 / 哪里可疑——选题的原材料

标签: [主题, 方法, 数据]   # 进记忆引擎的检索键
```

## 使用规则

- 检索上限 15 篇/轮：5 篇精读出卡，其余只记标题进"待读池"
- "缝"字段是唯一允许主观的字段，也最重要——Gap 定位图由它汇总
- 卡片存记忆引擎（跨会话累积）；watch_topic 的新论文先进待读池再决定是否出卡
