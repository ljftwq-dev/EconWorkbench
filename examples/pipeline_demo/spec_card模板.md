# spec_card 模板（研究卡片 · G0 门控物）

> 漏斗产出。填满才算过漏斗；作者签名后 driver 才肯开跑。

```yaml
# ===== 基本信息 =====
标题: <一句话标题>
作者观点: <最初那句观点，原话保留>
日期: YYYY-MM-DD

# ===== L1 贡献 =====
一句话发现: <这篇论文告诉我们什么以前不知道的东西>
对标文献: <最像的一篇 + 边际>
反事实拒稿信: <拒稿信第一段会写什么>

# ===== L2 识别 =====
变异来源: <政策/制度/横截面/时间结构>
识别策略: <DiD/事件研究/IV/RDD/结构断点/时变结构>
最可能死穴: <攻击点>
防御预案: <怎么挡>

# ===== L3 数据 =====
数据清单:
  - {变量: <y>, 来源: <库/镜像>, 口径: <当季/累计/月>, 跨度: <起-止>, 可达性: <直连/镜像/风险>}
  - {变量: <x>, ...}
样本量预判: <量级 + 平衡性>
备用数据源: <主源挂了的备选>

# ===== L4 稳健性预算 =====
必做三件: <1> <2> <3>
敏感性清单: <断点平移/窗口/聚类/口径...>
honest point: <哪个结果翻了论文就死>

# ===== 输出物 =====
表格: [主表, 稳健性表]
图: [主图, 事件研究图]
初稿: 中文四段式（引言/识别/结果/稳健性+政策启示）

# ===== 流水线接口（driver 读这里）=====
workdir: <项目目录，如 桌面\项目\xxx>
data_step: <取数脚本或说明；无则 manual>
estimate_step: <主实证脚本>
crosscheck_pairs: <对拍配置：实现A vs 实现B；无则 skip_crosscheck>
lint_config: {n_clusters: <n>, treatment: <staggered/...>}
data_audit_exempt: <[人工核查过的原始宽表文件名列表；分析用表勿豁免]>

# ===== 门控 =====
G0_放行: <空 = 未放行；作者签名+日期>
G1_放行: <空 = 未放行>
```
