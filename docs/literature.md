# L0 文献层：检索 → 文献卡 → Gap 定位

> 漏斗的前置层。没读过文献的人答不动 L1 的"你的贡献是什么"——L0 就是把这件事系统化。
> 选题 = **Gap × 数据可得性 × 自己的比较优势** 的交集。

## 三步协议

### ① 检索（工具不重造，MCP/API 已覆盖）

| 渠道 | 工具 | 适合 |
|---|---|---|
| arXiv | arxiv MCP（search/精读/引用图/BibTeX/watch_topic） | 方法论文（计量/ML/因果推断） |
| 学术元数据 | **OpenAlex API**（免费无 key，openalex.org） | 经济学期刊、引用数、作者网络 |
| 工作论文 | web 搜 NBER / SSRN / RePEc | 前沿（未必见刊） |
| 中文文献 | NCPSSD（国家哲学社会科学文献中心，官方免费） | CSSCI 语境 |
| 配套代码 | github / zread | 论文的开源实现 |

检索式模板：`主题词 AND (方法词 OR 数据词)`，中英各一轮；每轮上限 15 篇，宁精勿滥。

### ② 文献卡（templates/lit_card.md，每篇 5 行）

```
问题：这篇在回答什么问题？
方法：识别策略 + 估计量（DiD/IV/RDD/结构断点/…）
数据：数据源 + 口径 + 样本（跟你的可得性对照）
结论：核心系数方向量级 + 边际贡献声明
缝：它没回答什么/哪里可疑——**这条是选题的原材料**
```

### ③ Gap 定位图（喂给漏斗 L1 的"对标文献"字段）

三句话产出：
1. 已有研究在**哪**（最近 2-3 篇最像的，按文献卡排）
2. **缝**在哪（把所有"缝"字段汇总去重）
3. 为什么**这条缝我能缝**（数据/方法/视角，之一即可，诚实）

## 纪律

- 文献卡进记忆引擎（跨会话累积，越用越厚）
- watch_topic 订阅 2-3 个主题做持续跟踪，新论文进卡片流
- Gap 定位图写不出来 = 还没读够，回①不许进漏斗
- L0 产出与漏斗四层一起进 spec 卡片的「对标文献」「反事实拒稿信」字段
