# 漏斗：从一句话观点到研究 spec 卡片

> 原则：审稿人最终会问什么，漏斗就先问什么。brainstorm 的终点不是共识，是**填满的卡片**。

## 四层问题库（按序逼问，每层 2-4 问，作者答不上就降级/换题）

### L1 贡献层（先问死穴）
1. 一句话说清：这篇论文告诉我们什么**以前不知道**的东西？
2. 对标文献：最近哪篇最像？你的边际在哪（新数据/新识别/新异质性）？
3. 反事实审稿人（Top 5 标准）：拒稿信第一段会写什么？

### L2 识别层
1. 变异来源是什么（政策冲击/制度断点/横截面差异/时间结构）？
2. 识别策略落在哪类：DiD/事件研究/IV/RDD/结构断点/描述性时变结构？
3. 最可能的攻击点（内生性/测量误差/SUTVA/预趋势）→ 对应防御？

### L3 数据层（可得性预判，防"idea 很美数据没有"）
1. 每个变量的数据源、口径、频率、时间跨度？
2. 海外可达吗（国家局 403 类问题的备选镜像）？
3. 样本量量级 & 平衡性预判？

### L4 稳健性层（预算前置，不做马后炮）
1. 审稿人会要求哪三个稳健性？
2. 断点/窗口/聚类/口径的敏感性清单？
3. 哪个结果如果翻了，论文就死了（honest point）？

## 出口规则

- 四层全过 → 填 `templates/spec_card模板.md` → 展示给作者 → **G0 放行签名**
- 任一层答不上：记录到卡片「风险与死穴」，并明确降级预案（换数据/换设计/降目标期刊）
- 卡片没填满，禁止进流水线

## 漏斗纪律（GLM 自检）

- 只提问、只逼问、只结构化——**不放行**（放行是人专属动作）
- 优先用已有资产类比：因子库（617 卡）、审稿人 checklist、跨会话记忆里的既有研究
- 一轮最多 5 问，不要连环轰炸；作者累了就先落盘半成品卡片，下次续
